# NEEDS-HUMAN.md — decisions only the human can make

PARKED, not blocking. A builder writes here when a question is about vision,
scope, or a ratified contract — never when it is an engineering fork it can
decide and record. Work continues on the recorded default while an item waits;
if the build genuinely cannot proceed, that fact belongs in `STATUS.md`'s
`blocked_on`, which is where a watcher looks.

Newest at top. One item per heading, each self-contained: whoever reads this
has no chat history and should not need any.
